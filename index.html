Now building: Cyvire.

Security hiring is broken in both directions. Recruiters can't read the work, and practitioners get filtered by keyword. Cyvire fixes the pipe itself.

Cyvire is a cybersecurity-only hiring platform. No adjacent roles, no keyword bingo. It treats security work as evidence: what you ran, what you shipped, what passed audit.

I'm building it from the operator's side of the table, after seven years of hiring into and running SOC, compliance and cloud security teams.

  • 01Security-literate matching. Roles and people described in the language of the field, not HR taxonomy.
  • 02Evidence over keywords. Programmes delivered, frameworks passed, incidents handled.
  • 03Built by an operator. Designed around how security teams actually assess each other.
